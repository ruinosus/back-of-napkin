# back-of-napkin → house-lights

**This repository moved.** back-of-napkin is one of the five skills of
[house-lights](https://github.com/ruinosus/house-lights). Install it from there:

```
/plugin marketplace add ruinosus/house-lights
/plugin install house-lights@house-lights
```

If you installed `back-of-napkin` from this repository, remove it: `/plugin uninstall back-of-napkin@back-of-napkin`. Its files keep working
with the new skill. The gallery is now https://ruinosus.github.io/house-lights/back-of-napkin/; the npm command is
`npx house-lights back-of-napkin <file>`. This repository is archived and keeps its history and releases.
